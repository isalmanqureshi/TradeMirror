# TradeMirror Product Spec (Initial)

## Goal
Build a secure, production-oriented foundation for a RAG chatbot focused on trader self-review workflows.

## Core User Jobs
- Upload or connect trading history.
- Store journals and notes.
- Ask contextual questions grounded in user data and market context.

## Non-Goals (Phase 0)
- No live trading execution.
- No performance attribution engine.
- No strategy optimization logic.
